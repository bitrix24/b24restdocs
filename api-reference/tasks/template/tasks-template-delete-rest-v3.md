# Delete a Task Template v 3.0 tasks.template.delete

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup
- use the [MCP server](../../../ai-tools/mcp.md) to develop a REST API integration in your own project. The agent refers to the official REST documentation

{% endnote %}

> Scope: [`tasks`](../../scopes/permissions.md)
>
> Who can execute the method: an administrator, the template author, or a user with full access to the template

{% note info "" %}

This method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../rest-v3.md).

{% endnote %}

The `tasks.template.delete` method deletes a task template.

## Method Parameters

{% include [Note on required parameters](../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **id***
[`integer`](../../data-types.md) | Template ID.

The ID can be retrieved with the [tasks.template.list](./tasks-template-list-rest-v3.md) method ||
|#

If the Recycle Bin is available on Bitrix24, the template is moved there. Otherwise, the template is deleted permanently. After deletion, template methods return the "Record not found" error for this `id`.

The method does not support deletion by `filter`: pass the `id` of one template.

- Python

    The method name matches the previous version method `tasks.template.delete`, and REST 3.0 template methods are not yet included in the list of new version methods in `b24pysdk`: a regular SDK call goes to the previous REST version. Add the method to the `Config().api_v3_methods` list and call it via `bitrix_token.call_method` with `prefer_version=3`.

    ```python
    from b24pysdk import Config
    from b24pysdk.errors import BitrixSDKException
    from b24pysdk.errors.v3 import BitrixAPIError

    method = "tasks.template.delete"
    Config().configure(api_v3_methods=Config().api_v3_methods | {method})

    try:
        response = bitrix_token.call_method(
            api_method=method,
            params={
                "id": 151,
            },
            prefer_version=3,
        )
        print(response["result"]["result"])
    except BitrixAPIError as error:
        print(
            "Bitrix API error",
            f"code: {error.code}",
            f"message: {error.error.message}",
            sep="\n",
        )
    except BitrixSDKException as error:
        print(f"Bitrix SDK error: {error.message}")
    except Exception as error:
        print(f"Unexpected error: {error}")
    ```

### Possible Error Codes

#### Request Validation Errors

Error Code: `BITRIX_REST_V3_EXCEPTION_VALIDATION_REQUESTVALIDATIONEXCEPTION`

HTTP status: **400**

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | At least one of the required fields must be not empty: id, filter | Pass the template ID in `id` ||
|| `id` | Required field `id` is missing | Pass `id`. The method does not support deletion by `filter` ||
|| `id` | This request requires data type `integer` in field `id` | Pass a positive integer ||
|#

#### Access Denied

Error Code: `BITRIX_REST_V3_EXCEPTION_ACCESSDENIEDEXCEPTION`

HTTP status: **403**

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | Access denied | A template can be deleted by an administrator, the template author, or a user with the `full` permission. Check the permissions with the [tasks.template.access.get](./tasks-template-access-get-rest-v3.md) method ||
|#

#### Template Not Found

Error Code: `BITRIX_TASKS_V2_INFRASTRUCTURE_REST_EXCEPTION_TEMPLATE_NOTFOUNDEXCEPTION`

HTTP status: **404**

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `id` | Record with ID `149` was not found | The template does not exist or has already been deleted. Check the ID with the [tasks.template.list](./tasks-template-list-rest-v3.md) method ||
|#
