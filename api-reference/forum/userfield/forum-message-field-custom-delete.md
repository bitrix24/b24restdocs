# Delete Forum Message Custom Field forum.message.field.custom.delete

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup

{% endnote %}

> Scope: [`forum`](../../scopes/permissions.md)
>
> Who can execute the method: any user

{% note info "" %}

The method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../rest-v3.md).

{% endnote %}

The `forum.message.field.custom.delete` method deletes a custom field for forum messages together with its values in all messages.

## Method Parameters

{% include [Note on required parameters](../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **id***
[`integer`](../../data-types.md) | Identifier of the custom field to delete.

The identifier can be retrieved using the [forum.message.field.custom.list](./forum-message-field-custom-list.md) method.

Deleting by `filter` is not supported: such a request ends with an internal error ||
|#

### Possible Error Codes

#### Request Validation Errors

Error Code: `BITRIX_REST_V3_EXCEPTION_VALIDATION_REQUESTVALIDATIONEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | At least one of the required fields must be not empty: id, filter | Pass the custom field `id` ||
|| `-` | Only one of the following values must be provided: id, filter | Pass the custom field `id` ||
|#

#### Field Not Found Error

Error Code: `BITRIX_REST_V3_EXCEPTION_ENTITYNOTFOUNDEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `id` | Entity with ID `#ID#` was not found | There is no field with this `id`, or it has already been deleted. Check the identifier using the [forum.message.field.custom.list](./forum-message-field-custom-list.md) method ||
|#

#### Internal Error

HTTP status: **500**

The response comes in the format of the previous API version: `{"error":"INTERNAL_SERVER_ERROR","error_description":"Internal server error"}`.

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | Internal server error | The request contains `filter`. Pass the custom field `id` ||
|#
