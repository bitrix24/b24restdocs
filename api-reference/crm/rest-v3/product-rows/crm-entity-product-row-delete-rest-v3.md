# Delete a Product Item v 3.0 crm.[type].productrow.delete

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup
- use the [MCP server](../../../../ai-tools/mcp.md) to develop a REST API integration in your own project. The agent refers to the official REST documentation

{% endnote %}

> Scope: [`crm`](../../../scopes/permissions.md)
>
> Who can execute the method: a user with permission to edit the CRM item to which the product item belongs

{% note info "" %}

This method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../../rest-v3.md).

{% endnote %}

The `crm.<type>.productrow.delete` method deletes a product item from a CRM item. The object type is set by the `<type>` segment of the method name. The item amount is recalculated from the remaining product items unless it was set manually.

## Method Name for the Object Type

#|
|| **Object type** | **Method** ||
|| Deal | `crm.deal.productrow.delete` ||
|| Lead | `crm.lead.productrow.delete` ||
|| Estimate | `crm.quote.productrow.delete` ||
|| Invoice | `crm.smartinvoice.productrow.delete` ||
|| CRM document | `crm.smartdocument.productrow.delete` ||
|| SPA | `crm.smartprocess<entityTypeId>.productrow.delete`, for example, `crm.smartprocess1038.productrow.delete` ||
|#

For an SPA, the method name includes the type ID `entityTypeId`. SPA type IDs are returned by the [crm.type.list](../../universal/user-defined-object-types/crm-type-list.md) method in the `entityTypeId` field. An SPA has product item methods only if linking to catalog products is enabled in the type settings.

The method name is written in lowercase: `crm.smartinvoice.productrow.delete`, not `crm.smartInvoice.productRow.delete`. If the name is written in a different case, the method returns the ["Method Not Found"](#method-not-found) error.

## Method Parameters

{% include [Note on required parameters](../../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **id***
[`integer`](../../../data-types.md) | Product item ID.

The ID can be retrieved with the [crm.&lt;type&gt;.productrow.list](./crm-entity-product-row-list-rest-v3.md) method. The product item must belong to an item of the type set in the method name ||
|#

To delete all product items of an item in one call, pass an empty `items` array to the [crm.&lt;type&gt;.productrow.replace](./crm-entity-product-row-replace-rest-v3.md) method.

- Python

    `b24pysdk` has no ready-made wrappers for CRM methods, and the SDK sends to REST 3.0 only the methods from the `Config().api_v3_methods` list. Add the method to this list and call it via `bitrix_token.call_method` with `prefer_version=3`.

    ```python
    from b24pysdk import Config
    from b24pysdk.errors import BitrixSDKException
    from b24pysdk.errors.v3 import BitrixAPIError

    method = "crm.smartprocess1038.productrow.delete"
    Config().configure(api_v3_methods=Config().api_v3_methods | {method})

    try:
        response = bitrix_token.call_method(
            api_method=method,
            params={
                "id": 2415,
            },
            prefer_version=3,
        )
        result = response["result"]
        print(result)
    except BitrixAPIError as error:
        print(
            "Bitrix API error",
            f"code: {error.code}",
            f"message: {error.error.message}",
            sep="\n",
        )
    except BitrixSDKException as error:
        print(f"Bitrix SDK error: {error.message}")
    except Exception as error:
        print(f"Unexpected error: {error}")
    ```

#### Product Item Not Found

Error Code: `BITRIX_REST_V3_EXCEPTION_ENTITYNOTFOUNDEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | Entity with ID `#ID#` was not found | The product item does not exist, has already been deleted, belongs to an item of a different object type, or you do not have permission to edit the item. Check `id` with the [crm.&lt;type&gt;.productrow.list](./crm-entity-product-row-list-rest-v3.md) method and check the method name ||
|#

#|
|| **Field** | **Error description** | **How to Fix** ||
