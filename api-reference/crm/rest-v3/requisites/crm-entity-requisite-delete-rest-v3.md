# Delete a Requisite v 3.0 crm.[type].requisite.delete

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup
- use the [MCP server](../../../../ai-tools/mcp.md) to develop a REST API integration in your own project. The agent refers to the official REST documentation

{% endnote %}

> Scope: [`crm`](../../../scopes/permissions.md)
>
> Who can execute the method: a user with permission to edit the contact or company that owns the requisite

{% note info "" %}

This method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../../rest-v3.md).

{% endnote %}

The `crm.<type>.requisite.delete` method deletes a requisite of a contact or company together with its addresses and bank details. The owner type is set by the `<type>` segment of the method name. If the requisite was selected in a deal, invoice, or another item, the selection is cleared: [crm.&lt;type&gt;.clientrequisite.get](./crm-entity-client-requisite-get-rest-v3.md) returns `requisiteId: null`.

## Method Name for the Object Type

#|
|| **Object type** | **Method** ||
|| Company | `crm.company.requisite.delete` ||
|| Contact | `crm.contact.requisite.delete` ||
|#

Only contacts and companies have requisites. The owner type is set by the `company` or `contact` segment of the method name; the method does not find a requisite of a different owner type. My company requisites are available through the `crm.company.*` methods.

The method name is written in lowercase: `crm.company.requisite.delete`, not `crm.Company.Requisite.Delete`. If the name is written in a different case, the method returns the ["Method Not Found"](#method-not-found) error.

- Python

    `b24pysdk` has no ready-made wrappers for CRM methods, and the SDK sends to REST 3.0 only the methods from the `Config().api_v3_methods` list. Add the method to this list and call it via `bitrix_token.call_method` with `prefer_version=3`.

    ```python
    from b24pysdk import Config
    from b24pysdk.errors import BitrixSDKException
    from b24pysdk.errors.v3 import BitrixAPIError

    method = "crm.company.requisite.delete"
    Config().configure(api_v3_methods=Config().api_v3_methods | {method})

    try:
        response = bitrix_token.call_method(
            api_method=method,
            params={
                "id": 549,
            },
            prefer_version=3,
        )
        result = response["result"]
        print(result)
    except BitrixAPIError as error:
        print(
            "Bitrix API error",
            f"code: {error.code}",
            f"message: {error.error.message}",
            sep="\n",
        )
    except BitrixSDKException as error:
        print(f"Bitrix SDK error: {error.message}")
    except Exception as error:
        print(f"Unexpected error: {error}")
    ```
