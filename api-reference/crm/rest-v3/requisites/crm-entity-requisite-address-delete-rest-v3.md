> Scope: [`crm`](../../../scopes/permissions.md)
>
> Who can execute the method: a user with permission to edit the contact or company that owns the requisite

{% note info "" %}

This method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../../rest-v3.md).

{% endnote %}

The `crm.<type>.requisite.address.delete` method deletes the requisite address of the specified type. The requisite and its other addresses remain.

## Method Name for the Object Type

#|
|| **Object type** | **Method** ||
|| Company | `crm.company.requisite.address.delete` ||
|| Contact | `crm.contact.requisite.address.delete` ||
|#

A requisite address is identified by the pair of `requisiteId` and `typeId`: a requisite can have only one address of each type, and the address has no separate ID. The `company` or `contact` segment of the method name must match the owner of the requisite.

The method name is written in lowercase: `crm.company.requisite.address.delete`, not `crm.company.requisite.Address.Delete`. If the name is written in a different case, the method returns the ["Method Not Found"](#method-not-found) error.

## Method Parameters

{% include [Note on required parameters](../../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **requisiteId***
[`integer`](../../../data-types.md) | Requisite ID.

You can retrieve the ID with the [crm.&lt;type&gt;.requisite.list](./crm-entity-requisite-list-rest-v3.md) method ||
|| **typeId***
[`integer`](../../../data-types.md) | Address type, for example, `1` — actual address, `6` — legal address. The list of types is in the [requisite methods overview](./index.md#address-fields) ||
|#

- Python

    `b24pysdk` has no ready-made wrappers for CRM methods, and the SDK sends to REST 3.0 only the methods from the `Config().api_v3_methods` list. Add the method to this list and call it via `bitrix_token.call_method` with `prefer_version=3`.

    ```python
    from b24pysdk import Config
    from b24pysdk.errors import BitrixSDKException
    from b24pysdk.errors.v3 import BitrixAPIError

    method = "crm.company.requisite.address.delete"
    Config().configure(api_v3_methods=Config().api_v3_methods | {method})

    try:
        response = bitrix_token.call_method(
            api_method=method,
            params={
                "requisiteId": 549,
                "typeId": 6,
            },
            prefer_version=3,
        )
        result = response["result"]
        print(result)
    except BitrixAPIError as error:
        print(
            "Bitrix API error",
            f"code: {error.code}",
            f"message: {error.error.message}",
            sep="\n",
        )
    except BitrixSDKException as error:
        print(f"Bitrix SDK error: {error.message}")
    except Exception as error:
        print(f"Unexpected error: {error}")
    ```

#### Address or Requisite Not Found

Error Code: `BITRIX_REST_V3_EXCEPTION_ENTITYNOTFOUNDEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | Entity with ID `#ID#` was not found | The requisite has no address of this type, the requisite does not exist, it belongs to an owner of a different type, or you have no permissions for the owner. The error message contains `requisiteId` ||
|#

#### Method Not Found {#method-not-found}

Error Code: `BITRIX_REST_V3_EXCEPTION_METHODNOTFOUNDEXCEPTION`, HTTP status: **404**

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | Method `#METHOD#` was not found | Check the method name: it is written in lowercase, for example, `crm.company.requisite.address.delete`. Requisite methods exist only for contacts and companies: the `company` or `contact` segment ||
