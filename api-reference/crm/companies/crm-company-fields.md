# Get Company Fields Description crm.company.fields

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup
- use the [MCP server](../../../ai-tools/mcp.md) to develop a REST API integration in your own project. The agent refers to the official REST documentation

{% endnote %}

> Scope: [`crm`](../../scopes/permissions.md)
>
> Who can execute the method: a user with read permission for at least one CRM object type or SPA in a digital workplace

{% note warning "DEPRECATED" %}

The development of this method has been halted. Please use the REST 3.0 method [crm.company.field.list](../rest-v3/fields/crm-entity-field-list-rest-v3.md). The values of list fields are returned by the [crm.company.field.custom.enum.list](../rest-v3/fields/crm-entity-field-custom-enum-list-rest-v3.md) method.

{% endnote %}

The method `crm.company.fields` returns the description of company fields, including [custom fields](./userfields/index.md).

## Method Parameters

No parameters.
