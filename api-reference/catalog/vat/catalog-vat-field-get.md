> Scope: [`catalog`](../../scopes/permissions.md)
>
> Who can execute the method: any user

{% note info "" %}

The method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../rest-v3.md).

{% endnote %}

The `catalog.vat.field.get` method returns the description of a VAT rate field by its name.

## Method Parameters

{% include [Note on required parameters](../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **name***
[`string`](../../data-types.md) | The name of the field whose description you want to retrieve.

Available fields:

- `id` — VAT rate identifier
- `timestampX` — date and time of the last change
- `active` — rate activity
- `sort` — sort order
- `name` — rate name
- `rate` — rate value ||
|| **select**
[`array`](../../data-types.md) | An array of strings with the names of the description properties to return in the response.

Default: all description properties. The `["*"]` value is not supported.

Available fields:

- `name` — field name
- `type` — data type
- `title` — title
- `description` — description
- `validationRules` — validation rules
- `requiredGroups` — required operation groups
- `filterable` — filtering availability flag
- `sortable` — sorting availability flag
- `editable` — editability flag
- `editableGroups` — operation groups in which the field is editable
- `multiple` — multiple value flag
- `elementType` — element type for composite fields ||
|#

#### Item Object {#item}

The description contents depend on `select`. The table lists all properties that can be requested.

#|
|| **Name**
`type` | **Description** ||
|| **name**
[`string`](../../data-types.md) | Field name ||
|| **type**
[`string`](../../data-types.md) | Type in the metadata: `int`, `bool`, `string`, `float`, `object`. For `timestampX`, `object` is returned, although method responses pass the date as an ISO 8601 string ||
|| **title**
[`string`](../../data-types.md) | Field title. Matches `name` ||
|| **description**
[`string`](../../data-types.md) or `null` | Field description. `null` for the fields of this object ||
|| **validationRules**
[`array`](../../data-types.md) | Validation rules. `[]` for the fields of this object ||
|| **requiredGroups**
[`array`](../../data-types.md) or `null` | An array of strings with the names of the operations in which the field is required. `["add"]` for `name` and `rate`; `null` for the other fields ||
|| **filterable**
[`boolean`](../../data-types.md) | `true` — the field is available for filtering, `false` — it is not. `true` for all fields ||
|| **sortable**
[`boolean`](../../data-types.md) | `true` — the field is available for sorting, `false` — it is not. `true` for all fields ||
|| **editable**
[`boolean`](../../data-types.md) | `true` — the field can be passed in the operations from `editableGroups`, `false` — it cannot. `false` for `id` and `timestampX` ||
|| **editableGroups**
[`array`](../../data-types.md) or `null` | An array of strings with the names of the operations in which the field can be set. `["add", "update"]` for `active`, `sort`, `name`, `rate`; `null` for `id` and `timestampX` ||
|| **multiple**
[`boolean`](../../data-types.md) | Multiple value flag: `true` — multiple, `false` — single. `false` for all fields ||
|| **elementType**
[`string`](../../data-types.md) or `null` | Element type of a composite field. `null` for all fields ||
|#
