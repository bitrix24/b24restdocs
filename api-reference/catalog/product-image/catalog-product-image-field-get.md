# Get a Product Image Field catalog.product.image.field.get

{% note tip "" %}

Choose a tool for developing with an AI agent:

> Scope: [`catalog`](../../scopes/permissions.md)
>
> Who can execute the method: any user

{% note info "" %}

The method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../rest-v3.md).

{% endnote %}

The `catalog.product.image.field.get` method returns the description of a product image field by its name.

## Method Parameters

{% include [Note on required parameters](../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **name***
[`string`](../../data-types.md) | Name of the field whose description you need to retrieve.

Available fields:

- `id` — image identifier
- `productId` — product or variation identifier
- `type` — image type
- `name` — file name
- `createTime` — file upload date and time
- `detailUrl` — view link
- `downloadUrl` — download link
- `file` — image file ||
|| **select**
[`array`](../../data-types.md) | An array of strings with the names of the description properties to return in the response.

Available fields:

- `name` — field name
- `type` — data type
- `title` — title
- `description` — description
- `validationRules` — validation rules
- `requiredGroups` — required operation groups
- `filterable` — filtering availability flag
- `sortable` — sorting availability flag
- `editable` — editability flag
- `editableGroups` — operation groups in which the field is editable
- `multiple` — multiple value flag
- `elementType` — element type for composite fields

Default: all description properties. An empty array `[]` also returns all properties ||
|#

#### Item Object {#item}

The description content depends on `select`. The table contains all properties that can be requested.

#|
|| **Name**
`type` | **Description** ||
|| **name**
[`string`](../../data-types.md) | Field name ||
|| **type**
[`string`](../../data-types.md) | Type in the metadata: `int`, `string`, `object`. For `type`, `createTime`, and `file`, `object` is returned: in method responses, `type` and `createTime` are passed as strings and `file` as an object ||
|| **title**
[`string`](../../data-types.md) | Field title. Matches `name` ||
|| **description**
[`string`](../../data-types.md) or `null` | Field description. `null` for image fields ||
|| **validationRules**
[`array`](../../data-types.md) | Validation rules. An empty array for image fields ||
|| **requiredGroups**
[`array`](../../data-types.md) or `null` | Operations in which the field is required. `["add"]` for `productId`, `type`, and `file`, `null` for the other fields ||
|| **filterable**
[`boolean`](../../data-types.md) | `true` — the field is available for filtering. `true` only for `productId` ||
|| **sortable**
[`boolean`](../../data-types.md) | `true` — the field is available for sorting. `false` for all fields ||
|| **editable**
[`boolean`](../../data-types.md) | `true` — the field can be passed in the operations from `editableGroups` ||
|| **editableGroups**
[`array`](../../data-types.md) or `null` | Operations in which the field can be set. `["add"]` for `productId`, `type`, and `file`, `null` for the other fields ||
|| **multiple**
[`boolean`](../../data-types.md) | Multiple value flag. `false` for all fields ||
|| **elementType**
[`string`](../../data-types.md) or `null` | Element type of a composite field. `null` for all fields ||
