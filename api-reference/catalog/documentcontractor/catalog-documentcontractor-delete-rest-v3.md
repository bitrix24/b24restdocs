# Remove Vendor Binding from Document v 3.0 catalog.document.contractor.delete

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup
- use the [MCP server](../../../ai-tools/mcp.md) to develop a REST API integration in your own project. The agent refers to the official REST documentation

{% endnote %}

> Scope: [`catalog`](../../scopes/permissions.md)
>
> Who can execute the method: a user with the "Create and edit" and "View" permissions for documents of the "Incoming" type and the "View and select warehouses" and "View product catalog" permissions

{% note info "" %}

The method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../rest-v3.md).

{% endnote %}

The method `catalog.document.contractor.delete` deletes the binding of a CRM vendor to an incoming document.

## Method Parameters

{% include [Note on required parameters](../../../_includes/required.md) %}

#|
|| **Name**
`type` | **Description** ||
|| **id***
[`integer`](../../data-types.md) | Binding identifier.

The identifier can be retrieved using the [catalog.document.contractor.list](./catalog-documentcontractor-list-rest-v3.md) method or from the [catalog.document.contractor.add](./catalog-documentcontractor-add-rest-v3.md) response.

A binding can also be deleted from a processed document ||
|#

### Possible Error Codes

#### Request Validation Errors

Error Code: `BITRIX_REST_V3_EXCEPTION_VALIDATION_REQUESTVALIDATIONEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | At least one of the required fields must be not empty: id, filter | Pass the binding `id`. This message comes together with a second one: "Only one of the following values must be provided: id, filter" ||
|| `-` | Contractors should be provided by CRM | Document vendors are not taken from CRM. The methods work only if inventory document vendors are managed in CRM ||
|| `-` | CRM module is required for document contractors | The methods work only if the CRM module is installed ||
|#

#### Filter Format Error

Error Code: `BITRIX_REST_V3_EXCEPTION_INVALIDFILTEREXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `filter` | Invalid filter `filter` | The method does not support `filter`. Pass the binding `id` ||
|#

#### Object Not Found Error

Error Code: `BITRIX_REST_V3_EXCEPTION_ENTITYNOTFOUNDEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `id` | Entity with ID `#ID#` was not found | The binding does not exist or the document is not available to the user. Check the identifier using the [catalog.document.contractor.list](./catalog-documentcontractor-list-rest-v3.md) method ||
|#

#### Access Error

Error Code: `BITRIX_REST_V3_EXCEPTION_ACCESSDENIEDEXCEPTION`

#|
|| **Field** | **Error description** | **How to Fix** ||
|| `-` | Access denied | Check the user's permissions for incoming documents, warehouses, and the catalog ||
|#
