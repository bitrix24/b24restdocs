{% note tip "" %}

Choose a tool for developing with an AI agent:

> Scope: [`catalog`](../../scopes/permissions.md)
>
> Who can execute the method: a user with the "View and select warehouses" or "View product catalog" access permission

{% note info "" %}

The method belongs to REST 3.0. The call specifics and response format of the new API version are described in the [REST 3.0 overview](../../rest-v3.md).

{% endnote %}

The `catalog.document.mode.status` method returns whether inventory management is enabled.

## Method Parameters

No parameters.

### Returned Data

#|
|| **Name**
`type` | **Description** ||
|| **result**
[`object`](../../data-types.md) | An object with the response data ||
|| **result.status**
[`string`](../../data-types.md) | Inventory management status.

Possible values:

- `Y` — inventory management is enabled
- `N` — inventory management is disabled ||
|| **time**
[`time`](../../data-types.md#time) | Information about the request execution time ||
