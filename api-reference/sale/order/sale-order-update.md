# Update Order sale.order.update

{% note tip "" %}

Choose a tool for developing with an AI agent:

- use [Alaio Vibecode](../../../ai-tools/vibecode.md) to build an app for Bitrix24 from a task description without knowing any programming language. The agent writes the code and deploys the app to a server, with no manual hosting setup
- use the [MCP server](../../../ai-tools/mcp.md) to develop a REST API integration in your own project. The agent refers to the official REST documentation

{% endnote %}

> Scope: [`sale`](../../scopes/permissions.md)
>
> Who can execute the method: administrator

Updates order fields and returns the updated order.

The method does not change basket items, payments, or shipments — use the [sale.basketitem.*](../basket-item/index.md), [sale.payment.*](../payment/index.md), and [sale.shipment.*](../shipment/index.md) methods for them.

{% note warning "" %}

The method skips fields that cannot be changed without returning an error: the response is successful, but the values remain unchanged. There are two groups of such fields:

- `lid`, `personTypeId`, `currency`, `userId` — set only when the order is created
- `id`, `accountNumber`, `payed`, `deducted`, and other read-only fields — generated by Bitrix24

To find out which fields can be changed, check the `isImmutable` and `isReadOnly` attributes in the [sale.order.getFields](./sale-order-get-fields.md) response.

{% endnote %}
